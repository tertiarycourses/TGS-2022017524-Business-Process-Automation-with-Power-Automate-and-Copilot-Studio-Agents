# Published role criteria — open vacancies

> **Fictional classroom document.** Upload to: **Screening Agent → Knowledge**.
>
> These are the *published* criteria. The Screening Agent assesses against these and nothing else —
> which is only meaningful if the criteria are written down somewhere the agent can be checked
> against. That is what this file is for.

## Site Engineer (REQ-2026-014)

**Department:** Engineering · **Reports to:** Project Manager · **Location:** Singapore, site-based

### Essential criteria

| # | Criterion | How it is evidenced |
|---|---|---|
| E1 | Degree in Civil or Structural Engineering | Qualification field |
| E2 | Minimum 4 years' post-graduation site experience | Years of experience field |
| E3 | Experience in building construction or infrastructure | Sector field |
| E4 | Working knowledge of AutoCAD | Software named on the application |
| E5 | Eligible to work in Singapore | Declared on the application |

### Desirable criteria

| # | Criterion |
|---|---|
| D1 | Professional Engineer (PE) registration |
| D2 | Experience with Revit, Civil 3D or Tekla |
| D3 | Notice period of 8 weeks or less |

### Not criteria

The following are **not** assessed and must not appear in any assessment: age, race, religion,
gender, marital or family status, nationality beyond the right to work, disability, or the
institution attended.

## How the Screening Agent must report

For each candidate, against each essential criterion, exactly one of:

| Verdict | Meaning |
|---|---|
| **Met** | The application evidences it |
| **Not met** | The application evidences that it is not satisfied |
| **Cannot be determined** | The application is silent or ambiguous |

> **"Cannot be determined" is a real answer and must survive to the recruiter.** C-102 has a blank
> PE field: that is not "no PE", it is "the form does not say". An agent that reports it as *not met*
> has manufactured a fact, and the recruiter has no way to see that it did.
>
> This is the most useful thing in the Screening lab. An incomplete application is the normal case,
> and the pressure on a helpful model is always to resolve the ambiguity rather than report it.

No score. No ranking. No recommendation. The agent produces the assessment; a person decides.
