# Requisition Template

Copy, fill in every field, and paste into the chat. The agent needs all four fields
before it can submit.

```
Requester:      <your full name>
Item:           <what you are buying, with the vendor name if you have one>
Quantity:       <number of units>
Justification:  <the business reason, one or two sentences>
```

Notes
- The item and vendor name are passed exactly as written; check spelling before sending.
- The reference number comes back in the form REQ-yyyymmdd-XXXXXX. Keep it.
