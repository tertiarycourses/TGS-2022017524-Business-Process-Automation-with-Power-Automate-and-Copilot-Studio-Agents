# User Manual — Raise a Requisition

## What this skill does
Guides the Procurement Agent through collecting a complete purchase requisition and
submitting it with the **Lab 6 - Raise Requisition** tool, then reporting the reference
number the tool returned.

## When it activates
When a colleague wants to buy something, raise a purchase requisition, order supplies or
equipment, or asks whether a purchase needs approval.

## How to use it
1. Tell the agent what you want to buy.
2. The agent asks for **all missing fields in one message** — reply with the full list
   (see `templates/TEMPLATE.md` for the four fields).
3. The agent submits the requisition **once** and reads back the reference number.
4. Note the reference for follow-up with Procurement.

## What the agent will not do
- Invent a quantity or a justification you did not give.
- Correct or substitute the vendor name you typed.
- Say the purchase is approved, or estimate when it will arrive — submitting is not approval.
- Help route a purchase around an approval (order splitting, budget-code swaps, vendor
  switching) — that goes to procurement@keppelridge.example.
