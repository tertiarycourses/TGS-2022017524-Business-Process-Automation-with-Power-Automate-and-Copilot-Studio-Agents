# Blog Writing — teaching notes (trainer only, not packaged)

**The point of this agent is what it does not have.** No web search, no knowledge sources — the
brief is the only input. In class, put the Blog Agent's empty Knowledge rail next to the Research
Agent's full one and ask which agent you would rather audit. The starved one, every time: a wrong
fact in its draft has exactly one possible origin.

**The skill vs the instructions, here.** The instructions carry the permanent constraints (brief
is the only source, banned words, no publication claims). The skill carries the *craft* — shape,
title pattern, CTA rule — which only matters when the task is writing. Note the last section:
the pre-handoff checklist runs silently. An agent that narrates its checklist wastes the
reader's attention and teaches learners to accept narration as evidence — the Review Agent
exists precisely because self-checks are not evidence.

**Probe with the brief's gaps.** The best in-class demonstration: hand it a brief whose "Not
established" section lists the fee, then ask for the fee to be added (probe 5 / quick test 2).
The correct behaviour — refusal with a request for an updated brief — shows the pipeline's error
path working: gaps route back to Research, not into fiction.

**If drafts keep exceeding 700 words**, that is normal model behaviour, not a broken skill; the
Review Agent's checklist catches it. Resist "fixing" it by making this skill shout — the
pipeline, not any single prompt, is the quality mechanism.
