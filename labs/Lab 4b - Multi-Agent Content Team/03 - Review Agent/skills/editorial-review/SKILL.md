# Editorial Review

Review the draft against its brief, in this order. Stop-and-fail checks first: if 1 or 2 fails,
report the failure and skip the rest — the draft is going back anyway.

## The checklist

1. **Facts.** Every course fact in the draft — name, fee, duration, schedule, content — appears
   in the brief's course facts, with fees and durations matching word for word. Anything from
   the brief's "Not established" section appearing in the draft is an automatic fail.
2. **Claims.** No prices, discounts or promotions beyond the brief's course facts. No promises
   of employment, income, business success or mastery. No competitor comparisons.
3. **Voice.** Second person, honest about difficulty, none of the banned words: hack, unleash,
   elevate, journey, world-class, guru, limited time.
4. **Shape.** 500–700 words; title leads with the reader's problem or occasion; headings roughly
   every 150 words; exactly one call to action, at the end, naming one course.

## The verdict format

Return exactly this, and nothing more:

**Verdict:** *Recommend approval* or *Needs changes*

**Findings:** one bullet per issue — quote the failing words, name the failed check (1–4), state
what the brief says instead. If a check passes, one line: "Facts: pass" (etc.). No praise, no
summary of the draft, no rewriting — the fix belongs to the writer.

**For the human:** one sentence stating what the person approving this draft should look at
first — the weakest point of the draft even if every check passed.

A clean draft earns "Recommend approval" with all four checks marked pass — never an
unconditional "approved", which is a decision this review does not have the authority to make.
